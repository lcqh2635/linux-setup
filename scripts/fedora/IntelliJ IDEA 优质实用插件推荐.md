### 💡 科学使用建议（避坑指南）

1. **🚫 警惕“伪需求”插件**  
   IDEA 2024~2026 已内置大量原需第三方插件的功能：`Lombok`、`Database`、`Docker`、`Kubernetes`、`HTTP Client`、`JSON Parser`、`Markdown`、`Swagger/OpenAPI`、`Git` 增强等。**安装前务必搜索确认是否重复**。

2. **🤖 AI 插件只留 1~2 个**  
   同时开启多个 AI 助手会导致：
   
   - 内存占用飙升（每个常驻 200~500MB）
   - 快捷键冲突（如 `Ctrl+Space`、`Alt+Enter` 拦截）
   - 补全结果互相覆盖  
   ✅ 建议：主用 `Lingma`，按需临时启用 `Continue` 或 `Codeium`。
   
3. **⚡ 性能优化技巧**
   - 在 `Settings → Plugins → Installed` 中右键非当前项目插件 → `Disable`，可显著降低启动时间与内存峰值。
   - `MyBatis Log`、`Better Comments`、`PlantUML` 等轻量插件对性能影响极小，可常驻。
   - 定期执行 `File → Invalidate Caches` 清理插件索引缓存。

4. **📦 插件管理最佳实践**
   ```text
   常驻核心：SonarQube for IDE / GitToolBox / Save Actions X / Rainbow Brackets / Lingma
   按需加载：MyBatis Log / PlantUML / DevContainer / WakaTime / Presentation Assistant
   临时启用：Error Prone / Codeium / AWS Toolkit / Mermaid
   ```
